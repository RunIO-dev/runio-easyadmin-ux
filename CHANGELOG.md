## [0.1.0] - 2026-11-24

First public release. Requires EasyAdmin 5.10+, PHP 8.2+, and Symfony 6.4, 7.x, or 8.x.

### Added
- Four layouts that each user can switch between: Sidebar, Compact, Top navigation, and Focus.
- Command palette (Ctrl+K) and link prefetching that skips logout and impersonation links.
- Smart tables: column picker with drag and drop, row density, saved views, and range selection.
- Inline cell editing and an edit drawer, both submitting EasyAdmin's own forms so validation and permissions still apply.
- Per-user customizable dashboards with metric, list, and bar chart widgets and role-based visibility.
- Arabic translations and full right-to-left support.
